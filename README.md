# News_credibility_assessment
A multi-user NLP and conversational AI system for assessing news credibility and providing related coverage for context.
The rapid spread of misinformation on digital platforms poses a growing risk to public discourse and decision-making. This project develops a shared platform that helps multiple users evaluate the credibility of news content by combining natural language processing, conversational AI, and source-based verification techniques.

Core functions

Credibility assessment: evaluates the reliability of a news item by analysing its publishing source and verifying whether the author is a credible or professional journalist.
Contextual news retrieval: surfaces related articles from other sources, so users can cross-reference claims and understand the wider context of a story.
Concurrent multi-user access: supports multiple users submitting verification requests simultaneously, with each user's queries handled independently.

Approach: the system combines source and author verification with NLP-based analysis of content. Additional detection methods will be explored and integrated as the project evolves.

Status: in active development (started September 2026). This is a solo project.
